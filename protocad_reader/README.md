# protocad_reader — читатель файлов ProtoCAD

Открывает `.prcadPart`, `.prcadAsm`, `.prcadDraw`: состав, спецификация,
модель для просмотра, чертежи, связи с записями ПРОТО.

## Это отдельное произведение, а не часть ядра ProtoCAD

Читатель предназначен для встраивания в **ПРОТО — закрытый коммерческий
продукт**. Поэтому его лицензионный контур обязан быть независим от контура
CAD-ядра.

Практически это значит: **читатель не должен зависеть ни от чего с сильным
копилефтом**. Ядро ProtoCAD сейчас связано GPL-3 через решатель ограничений
SolveSpace; если читатель окажется частью того же произведения, встраивать
его в ПРОТО будет нельзя.

Сейчас граница соблюдена:

| Зависимость | Лицензия |
|---|---|
| стандартная библиотека Python | PSF |
| numpy (только для мешей) | BSD-3 |

Ни FreeCAD, ни OCCT, ни решателя ограничений здесь нет и быть не должно.
Проверяется запуском `python protocad_reader/selftest.py <файл>` — он
печатает список загруженных модулей CAD-ядра и ожидает, что тот пуст.

## Выбор лицензии

Не сделан, это решение владельца продукта. Разумные варианты:

* **MIT** — максимальная свобода встраивания, в том числе в закрытое ПРОТО;
* **LGPL-2.1** — встраивание тоже возможно, но правки самого читателя
  придётся публиковать.

Пока лицензия не выбрана, файл существует как напоминание, что вопрос
открыт и что нарушить границу легко: достаточно один раз импортировать
что-нибудь из ядра.

## Использование

```python
from protocad_reader import open_container

doc = open_container("АБВГ.687281.001.prcadAsm")
doc.designation          # обозначение
doc.bom()                # строки спецификации
doc.tree()               # дерево состава
mesh = doc.preview()     # вершины, нормали, рёбра для отрисовки
doc.resolve(mesh_id=17)  # что за тело под курсором → ЭРИ → запись ПРОТО
doc.drawings()           # листы чертежей
```
