# ЗАМОРОЖЕНО. Доказательная база Spike 2

Аддон для FreeCAD, которым проверялась реализуемость требований A1–A6 и
B1–B5. На нём стоят результаты в [`results/feasibility.md`](../results/feasibility.md),
поэтому каталог сохраняется неизменным и должен оставаться воспроизводимым.

**Развивать не здесь.** Продуктовый код — в [`protocad/`](../protocad/): он
самостоятельный, работает на OCCT напрямую и FreeCAD не требует (Spike 4).

## Чем этот код отличается от продуктового

| | addon (заморожен) | protocad (развивается) |
|---|---|---|
| Геометрия | `Part` из FreeCAD | OCCT напрямую |
| Проекции чертежа | `TechDraw.project` | `HLRBRep` |
| Документ | `App::Link`, `Part::FeaturePython` | структуры Python |
| Состав | плата смешана с подложкой | сборочная единица по ЕСКД |
| Вложенность | одноуровневая | произвольная, с контролем циклов |
| Запуск | нужен установленный FreeCAD 1.1 | `.venv` на Python 3.12 |

## Как запустить, если понадобится перепроверить Spike 2

Нужен установленный FreeCAD 1.1+ и системный Python 3.11 (не `.venv`):

```bash
python scripts/run_spike2.py --install
```

Устанавливает аддон в пользовательский каталог FreeCAD и прогоняет все 11
проверок. Каталог addon определяется у самого FreeCAD через
`getUserAppDataDir()` — он версионный (`%APPDATA%/FreeCAD/v1-1/Mod`), и
установка мимо него молча игнорируется.
