# Зависимости ProtoCAD (ставятся pip).

# FreeCAD 1.1 ставится ОТДЕЛЬНО, обычным установщиком: он — движок окна

# работает в своём процессе со своим Python. Сборка, подготовка к расчёту,

# --- ядро геометрии ---
# Верхняя граница обязательна: OCP 8 поменял привязки (`Bnd_Box.Get()` и
# др.), и с ним ядро падает на первом же габарите. Снимать её — только
# после прогона проверок на новой версии.
cadquery-ocp>=7.9,<7.10    # OCCT 7.9 через привязки OCP, Apache-2.0
numpy>=1.26                # буферы вершин и матрицы, BSD-3

# --- интерфейс ---
PySide6>=6.6               # окна и контекст OpenGL, LGPL-3
PyOpenGL>=3.1              # вызовы GL, BSD

# --- решатель ограничений ---
# planegcs — LGPL-2.1+, решатель из FreeCAD. Требует Python >= 3.12:
# на 3.10–3.11 колёс нет, и эскизы остаются без решателя.
#
# py-slvs (SolveSpace, GPL-3) здесь НЕ ставится: по THIRD_PARTY.md он
# только для проверок и в поставку не входит. Строка с ним в этом файле
# тащила GPL-3 в рабочее окружение при обычном `pip install -r`.
planegcs>=0.8; python_version >= "3.12"
