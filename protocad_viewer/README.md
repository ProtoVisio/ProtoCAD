# protocad_viewer — просмотрщик файлов ProtoCAD

Окно просмотра для встраивания в ПРОТО: модель, состав, спецификация,
чертежи. Вращение, приближение, выбор тела с подсветкой в дереве.

```bash
python protocad_viewer/app.py "work/АБВГ.687281.001.prcadAsm"
```

## Это отдельное произведение, а не часть ядра ProtoCAD

Как и [protocad_reader](../protocad_reader/README.md), просмотрщик
предназначен для **закрытого коммерческого ПРОТО**, поэтому его
лицензионный контур независим от контура CAD-ядра.

Зависимости и их лицензии:

| Зависимость | Лицензия | Замечание |
|---|---|---|
| protocad_reader | будет выбрана | тот же контур |
| numpy | BSD-3 | |
| PyOpenGL | BSD | |
| PySide6 | **LGPL-3** | встраивание допустимо при динамической линковке |

Ни FreeCAD, ни OCCT, ни решателя ограничений здесь нет. Отрисовка идёт по
готовым буферам из контейнера — CAD-ядро для просмотра не нужно, в этом и
был смысл класть просмотровые данные внутрь файла.

PySide6 под LGPL-3 встраивание в закрытый продукт не запрещает, но требует
возможности заменить саму библиотеку. Если ПРОТО уже использует PySide6 —
а он использует, — вопрос там уже решён.

## Что осталось

* лицензия не выбрана — решение владельца продукта;
* метка изделия в дереве приходит с суффиксом вида `…Плата печатная001`:
  FreeCAD дописывает номер при совпадении имён, надо чистить при записи
  контейнера;
* FPS в статусной строке достоверен только в живом окне; в дымовом прогоне
  без цикла отрисовки он показывает почти ноль.
