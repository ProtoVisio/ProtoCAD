# ProtoCAD

Открытая часть ПРОТО: параметрическое моделирование на ядре Open CASCADE.
Оформление документов по ЕСКД и остальная инженерная среда живут отдельно и
закрыты; здесь — код геометрии, эскиза, сборки и просмотра.

Лицензия — **LGPL-2.1-or-later**, см. [LICENSE](LICENSE). Сторонние
компоненты и их лицензии разобраны в [THIRD_PARTY.md](THIRD_PARTY.md) и
[SBOM.md](SBOM.md).

## Что здесь лежит

| | |
|---|---|
| `protocad/` | ядро: документ, элементы, эскиз, сборка, чертёж, обмен форматами |
| `protocad/prep/` | подготовка геометрии к расчёту: проверка, лечение, упрощение, сетка |
| `protocad_app/` | приложение: команды, панели, лента, редакторы |
| `protocad_prep/` | окно подготовки к расчёту |
| `protocad_gl/` | вьюпорт на OpenGL |
| `protocad_reader/` | чтение контейнера документа |
| `protocad_viewer/` | отдельный просмотрщик |
| `prep_tests/` | проверки подготовки к расчёту (pytest) |
| `addon/` | верстак для FreeCAD |

## Требования

Python 3.12 и новее: решатель эскизов `planegcs` собран только под 3.12+, на
более старом питоне эскизы остаются без решателя. Зависимости — в
[requirements.txt](requirements.txt);
геометрическое ядро приходит через `cadquery-ocp` (Open CASCADE), решатель
эскизов — `planegcs`, интерфейс — PySide6.

```bash
python -m venv .venv
.venv/Scripts/activate      # Windows
python -m pip install -r requirements.txt
```

## Подготовка к расчёту

Путь модели от CAD до решателя:

```
STEP / IGES / BREP / деталь ProtoCAD
  → проверить → исправить → упростить → симметрия / разделить / склеить /
    область течения → группы граней и тел → сетка → файл решателя
```

Окно: `python protocad_prep/app.py [деталь.step]`, из конструирования —
«Файл → Подготовка к расчёту…». Грани выбираются щелчком (Ctrl — добавить),
группа граней — это граничное условие, группа тел — материал.

Всё, что сделано в окне, сохраняется **рецептом** и повторяется на новой
версии детали одной командой — без окна:

```bash
python -m protocad.prep check  деталь.step
python -m protocad.prep holes  деталь.step --diameter 8
python -m protocad.prep run    деталь.prep.json --source деталь-v2.step
```

Группы в рецепте лучше задавать правилом, а не выбором мышью: «плоская грань
с нормалью вниз, самая нижняя» найдётся и в следующей версии детали. Правила
описаны в `protocad/prep/select.py`, формат рецепта — в
`protocad/prep/recipe.py`.

Сетка строится [gmsh](https://gmsh.info) в **отдельном процессе**. gmsh
распространяется под GPL-2+, поэтому в `requirements.txt` его нет: он ставится
отдельно (`requirements-mesh.txt`), а ProtoCAD запускает его как программу и
обменивается файлами — так же с gmsh работает FreeCAD FEM. Питон с gmsh
указывается переменной `PROTOCAD_GMSH_PYTHON`.

| Файл | Для чего |
|---|---|
| `.inp` | CalculiX, Abaqus — свой писатель: `C3D4`/`C3D10`, `*NSET` и `*SURFACE` для групп граней, `*ELSET` для тел и материалов |
| `.med`, `.unv` | Code_Aster, Salome |
| `.msh` | gmsh, Elmer, OpenFOAM (`gmshToFoam`, версия 2.2) |
| `.cgns`, `.su2` | CFD-решатели |
| `.bdf` | Nastran |
| `.vtk` | ParaView |
| `.stl` | поверхность; из окна — с именованными частями для snappyHexMesh |

Имена групп в файлах решателя — латиницей (CalculiX и CGNS кириллицу не
принимают): «Заделка» становится `Zadelka`, перевод печатается в итоге шага.

Проверки: `python -m pytest prep_tests` (тест окна — под `xvfb-run` или с
дисплеем). Среди них — расчёт консоли в CalculiX по сгенерированному `.inp`:
прогиб сходится с формулой сопромата в пределах 2%.

## Чего в этом репозитории нет

Проект прошёл исследовательскую фазу: два измерительных прогона, от которых
зависела архитектура. Задание, результаты замеров и оркестраторы прогонов
остались во внутреннем дереве — они описывают, **как принималось решение**, а
не то, как работает код.

Поэтому строки документации в коде ссылаются на документы вроде
`docs/08_ENGINE_BACKEND.md`, которых здесь нет. Ссылки оставлены как есть:
переписывать их задним числом значило бы потерять след, откуда правило взялось.

Там же остались проверки на втором решателе (`py-slvs`, GPL-3): они намеренно
изолированы от рабочего кода и в поставку не входят — см. THIRD_PARTY.md.
